# Vairagya Events – Venue Map

Interactive venue site map by Vairagya Events.

- **3D view** (`index.html`): rotate, pinch-zoom and tap any area for details; overview, top, guest, entry and night views.
- **2D plan** (`plan.html`): illustrated top-down layout with sizes, capacities and notes.

Live site: https://vansh-nisar.github.io/vairagya-venue-map/

Layout, names and figures are sample data for demonstration.
